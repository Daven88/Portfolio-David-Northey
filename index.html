RBA Interest Rate Pipeline

End-to-end batch and streaming pipeline on GCP for Australian interest rate data. Ingests macro-economic indicators from the World Bank API, transforms through a Bronze→Silver→Gold Medallion architecture using dbt, orchestrates with Apache Airflow (Docker), and applies machine learning to predict the direction of RBA rate decisions. Extended with a GCP Pub/Sub streaming module for real-time event ingestion alongside the batch pipeline.

Stack: Python, SQL, dbt, Apache Airflow, Docker, GCS, BigQuery, Pub/Sub, scikit-learn, Looker Studio
